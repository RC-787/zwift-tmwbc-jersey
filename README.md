# zwift-tmwbc-jersey
Custom jersey for use in Zwift

## Install instructions

1) Download the file named "ZwiftStandardOrange.ztx" from this repository
2) Navigate to your zwift install directory. On windows, this should be "C:\Program Files (x86)\Zwift"
3) In the zwift install directory, open the "/data/Humans/Jerseys/Originals" directory
4) Take a backup of the existing "ZwiftStandardOrange.ztx" file (for example, rename it "ZwiftStandardOrange.backup.ztx"
5) Copy the "ZwiftStandardOrange.ztx" file that you downloaded from Github and paste it into the "/data/Humans/Jerseys/Originals" directory
6) Launch the Zwift application
7) Open "My Garage" and click on the "Jersey" button
   ![description](https://github.com/RC-787/zwift-tmwbc-jersey/blob/main/screenshots/Readme1.png)
8) Select the "Zwift Standard Orange" option. Our custom jersey will be rendered instead of the normal orange jersey
    ![description](https://github.com/RC-787/zwift-tmwbc-jersey/blob/main/screenshots/Readme2.png)
9) Enjoy!
